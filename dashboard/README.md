# E-Commerce Dashboard

## 1. Overview

This folder is dedicated to the dashboard and business intelligence visualization component of the E-Commerce Customer Behaviour and Sales Intelligence project.

The dashboard uses the analytical datasets created in the Gold layer of the Databricks data engineering pipeline.

## 2. Dashboard Tools

The dashboard will be developed using :

- Tableau

## 3. Data Sources

The dashboard uses the following seven Gold-layer datasets:

1. gold_orders
2. gold_daily_sales
3. gold_product_performance
4. gold_customer_analytics
5. gold_payment_analytics
6. gold_delivery_analytics
7. gold_review_analytics

These datasets are exported from Databricks and shared with the dashboard development team.

## 4. Planned Dashboard Insights

The dashboard is intended to present:

- Total orders and revenue
- Daily sales trends
- Product and category performance
- Customer purchasing behaviour
- Payment method distribution
- Delivery performance and delays
- Customer review scores and satisfaction

## 5. Team Responsibility

Member 4 is responsible for:

- Importing the Gold datasets.
- Designing dashboard pages and visualizations.
- Creating relevant KPIs and filters.
- Presenting business insights.
- Integrating dashboard screenshots into the final project documentation.
